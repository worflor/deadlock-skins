# woflo's Deadlock skins

Finished releases of my Deadlock hero skins, hosted as a mod source for Deadlock Mod Manager.

**Page and downloads: https://woflo.dev/deadlock-skins/**

In a Deadlock Mod Manager version with mod sources (Settings > Mods > Mod sources), add
`https://woflo.dev/deadlock-skins/dmm-source.json` once to get the skins and their updates in the Mods Store.
Otherwise download the zip from the page; its README has the install steps.

Fan-made, cosmetic only, not affiliated with Valve. Each download carries its own licence terms.

Each skin is a folder under `skins/`; the page, the catalog and the downloads are built from those folders on every
change. How it works: [CONTRIBUTING.md](CONTRIBUTING.md).
